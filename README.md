# Interview Room

지원 정보와 예상 질문을 바탕으로 진행되는 한국어 AI 모의면접 웹 앱입니다.

## 실행

Node.js 18 이상에서:

```powershell
$env:GEMINI_API_KEY="YOUR_KEY"
npm start
```

또는 프로젝트 루트의 `.env` 파일에 `GEMINI_API_KEY="YOUR_KEY"`를 작성하면 서버가 시작할 때 자동으로 불러옵니다.

그런 다음 `http://localhost:4173`을 엽니다. Gemini 키 없이도 데모 평가 모드로 전체 흐름을 체험할 수 있습니다.

## 기능

- 면접 시간, 회사/직무, 면접 종류·형식·난이도 설정
- 기업, 대학원, 동아리·학회, 공공기관 등 면접 대상별 맞춤 입력
- 지원서·예상 질문 PDF 다중 첨부 및 Gemini 교차 분석 (각 최대 5개, 파일당 10MB)
- 예상 질문 자료가 없어도 지원서만 분석한 맞춤 질문 자동 생성
- 면접 시작 시 자료를 한 번만 분석하고 이후 답변 평가는 요약된 면접 브리핑 재사용
- 전면 카메라 셀프 뷰 (영상은 서버로 전송되지 않음)
- 브라우저 TTS로 면접관 질문 낭독
- Web Speech API를 이용한 한국어 STT 및 직접 입력 폴백
- Gemini 기반 답변 평가, 개선 답변, 맥락형 꼬리질문
- 질문별 피드백 및 전체 점수 리포트

## 참고

- Chrome/Edge에서 카메라와 음성 인식 지원이 가장 안정적입니다.
- 실제 배포 시 HTTPS가 필요합니다. 로컬의 `localhost`에서는 카메라 권한을 사용할 수 있습니다.
- 모델을 바꾸려면 `GEMINI_MODEL` 환경변수를 설정하세요. 기본값은 `gemini-3.6-flash`입니다.
